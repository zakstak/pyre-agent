Internal visual reference

Tokens and components for internal tools, review pages, and reports. A product's own design system takes precedence.

Decisions

Atkinson Hyperlegible Next is the reading font. Atkinson Hyperlegible Mono is the technical font. The palette is calm charcoal and violet layers with lavender focus and dusty pink primary actions. Light and dark modes follow the system until the reader picks one.

  • Content sets the layout. Use a sidebar or columns only when the content has that shape.
  • One primary action per view. Everything else is a default or quiet button.
  • Status color always comes with words.

Color roles

Use roles, not hex values. Each role switches with the mode.

  • Page--bg-page
  • Surface--bg-surface
  • Raised--bg-raised
  • Code and inputs--bg-code
  • Primary text--text-primary
  • Secondary text--text-secondary
  • Accent, links, focus--pyre-accent
  • Primary action--pyre-action
  • Success--status-success
  • Warning--status-warning
  • Danger--status-danger
  • Separator--separator

Acceptance checks

Reading

Short paragraphs keep the current idea visible. Prose stays near 68 characters wide; code and comparison areas may run wider. A font choice does not guarantee a reading outcome, so keep zoom, text spacing, and system accessibility settings available.
